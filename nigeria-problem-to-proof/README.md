# Nigeria Problem to Proof

Next.js (app router) teaser landing page.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Structure
- `app/page.tsx` – hero (with `/hero-tv-tech.png`), concept, journey timeline, final CTA
- `app/coming-soon/page.tsx` – `/coming-soon` route (all Register buttons go here)
- `app/globals.css` – all styles
- `public/hero-tv-tech.png` + `.webp` – hero image
